# OctoAcme Project Management Docs

This README provides a short summary of OctoAcme's project management processes and links to the full process documents in the docs/ folder.

## Summary
OctoAcme uses an iterative, customer-first project management approach with the following stages:

- Initiation: capture problem, stakeholders, and outcomes (one-pager)
- Planning: create prioritized backlog, estimates, and release milestones
- Execution: implement in short increments with CI, PR review, and testing
- Release: pre-release checks, deployment, and post-deploy verifications
- Retrospective: capture learnings and track improvement action items
